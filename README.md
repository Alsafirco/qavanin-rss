# خوراک RSS سامانه ملی قوانین و مقررات

این مخزن یک خوراک RSS از تازه‌ترین اسناد فهرست‌شده در [qavanin.ir](https://qavanin.ir/) تولید می‌کند.

## نشانی مستقیم خوراک

https://raw.githubusercontent.com/Alsafirco/qavanin-rss/main/feed.xml

## به‌روزرسانی
GitHub Actions هر ساعت دو بار (تقریباً هر ۳۰ دقیقه) صفحه اصلی را بررسی می‌کند و در صورت تغییر فهرست، فایل `feed.xml` را به‌روز می‌کند. اجرای دستی نیز از زبانه Actions و گزینه **Update Qavanin RSS → Run workflow** ممکن است.

## نکته
این خوراک غیررسمی است و از صفحه عمومی وب‌سایت استخراج می‌شود؛ تغییر ساختار سایت ممکن است نیازمند به‌روزرسانی اسکریپت باشد. پیوند هر مورد به سند اصلی در qavanin.ir می‌رود.
