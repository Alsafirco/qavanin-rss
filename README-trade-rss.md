# RSS یکپارچه گمرک، صادرات و واردات ایران

**آدرس فید:** https://raw.githubusercontent.com/Alsafirco/qavanin-rss/main/trade-feed.xml

این خوراک خبرهای مرتبط با گمرک، صادرات، واردات، تعرفه‌ها، ثبت سفارش، ترخیص کالا، بخشنامه‌ها، مناطق آزاد، ترانزیت و حمل‌ونقل را از منابع ایرانی تجمیع می‌کند.

- نتایج جست‌وجوی خبری محدود به سازمان توسعه تجارت ایران (tpo.ir)
- جست‌وجوی خبرهای بخشنامه و تعرفه‌های تجاری ایران

## به‌روزرسانی
GitHub Actions هر ۳۰ دقیقه اجرا می‌شود و امکان اجرای دستی از زبانه Actions نیز وجود دارد. موارد تکراری حذف و حداکثر ۱۵۰ خبر مرتبط نگهداری می‌شوند.

## نکته
این یک تجمیع‌کننده مستقل و غیررسمی است. برخی سایت‌های رسمی RSS عمومی قابل‌دسترسی ندارند؛ برای آن‌ها از فید جست‌وجوی Google News با محدودیت دامنه استفاده شده است. اگر یک منبع موقتاً در دسترس نباشد، سایر منابع همچنان پردازش می‌شوند.

فقط کانال‌های عمومی قابل مشاهده بدون ورود یا عضویت قابل پردازش‌اند. کانال خصوصی، گروه‌ها و محتوای نیازمند عضویت در این روش پوشش داده نمی‌شوند. دسترسی هر کانال ممکن است تغییر کند؛ در صورت خطای یک کانال، سایر منابع همچنان پردازش می‌شوند.
